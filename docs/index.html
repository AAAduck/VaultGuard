VaultGuard

把私密文件加密成一张普通图片（或 Word 文档）的保险箱。存网盘、发给别人都看不出来，只有知道口令的人能还原。

离线 · 单文件 · 免安装 · 开源（MIT）

这是什么？

一句话：把你的私密文件变成一张看起来完全正常的图片或 Word 文档，只有知道口令的人能把它还原回来。

例如你有一份工资单想存网盘：用 VaultGuard 加密后，网盘里出现的是一张风景图 VG_20260906_3f8a.png，谁看了都以为就是张图；需要时拖回软件、输入口令，工资单原样回来。全程在本机完成，不需要联网、不注册账号，只有一个约 5MB 的 exe 文件。

什么场景有用

网盘存私密文件

证件扫描件、工资单、日记、病历……加密后再上传，网盘只能存一张"图片"，看不到读不出内容。

发给指定的人

把加密"图片"通过微信/邮件发出，口令用电话等另一渠道告知；对方装入软件、输入口令即可还原。

防随手翻看

文件伪装成图片放电脑里，家人朋友、借电脑的人不会起疑点开；翻到了也打不开。

长期整理资料

「隐私保险箱」一个口令对应一个资料库，随时加文件、删文件，像加密文件夹一样。

什么场景别用它（诚实说明） 忘记口令，神仙也救不回来——没有"找回口令"功能，这是安全性的代价；它防的是"人"，不保证骗过网盘自动扫描系统（加密数据的统计特征理论上可被识别），请勿存放违法违规内容；面对专业黑客和取证分析，请使用 VeraCrypt 等专业工具。

三步上手

  1. 添加文件：把文件或文件夹拖进窗口（或点左栏「文件」「文件夹」按钮）；
  2. 设置口令：在「口令」区输入并确认。口令是唯一的钥匙，忘了就打不开，请务必记牢（重要口令建议抄在纸上放安全处）；
  3. 选外壳、点加密：选伪装外壳（PNG / JPG / DOCX），点「开始加密」。产物默认保存在 outputs\。

还原：把加密产物拖回窗口，输入同一口令，点「还原 VaultGuard 文件」。加密与还原都生成新副本，绝不动原文件。

命令行：也支持拖拽与 CLI，例如 VaultGuard.exe "D:\资料\项目文件夹" --png --password-stdin（用标准输入传口令，避免进命令行历史）。

常见问题

忘记口令了怎么办？

无法找回。没有后门，谁都解不开（包括作者）。这是安全性的组成部分，请设置自己记得住的口令。

加密后的"图片"发到网上，别人能看出破绽吗？

别人看到的是一张正常显示的图片。但内容已加密，懂技术的人或网盘的自动系统有可能识别出"这个文件里藏了东西"。用来保护个人隐私没问题，不要用来藏违规内容。

口令输错了会怎样？

提示"认证失败：口令错误"，文件不会损坏，重新输对口令即可（解密侧先认证、通过后才落位）。

加密后原来的文件还在吗？

在。加密和还原都生成新文件，绝不动你的原文件。

这个软件联网吗？会收集信息吗？

完全离线运行，没有任何联网、上传、遥测功能。

不设口令会怎么样？

文件使用"内置密钥"——任何拿到本软件的人都能解密，只防"别人不知道有这个软件"。存敏感文件请务必设置口令。

怎么把加密文件发给别人？

把"图片"文件发给对方，再用别的渠道（电话、语音等）告知口令；对方需要同样装有 VaultGuard。软件内「分享说明」按钮会生成含口令的复制文案。

杀毒软件报毒（如 VHO:Trojan-PSW…）怎么办？

这是对未签名、新编译程序常见的启发式误报（VHO = 启发式判定，非已知病毒库命中）。源码完全公开、完全离线。处理：①到 GitHub Releases 下载 SHA256SUMS 校验 exe 未被篡改；②到 opentip.kaspersky.com 提交误报申诉；③本地加白名单应急。

如何安装与更新？

单文件免安装：下载 exe 即用。更新即下载新版本 exe 替换。Scoop 上架后可用 scoop install vaultguard 管理；winget 待代码签名后上架（见安装与校验）。

这个项目开源吗？

开源，MIT 许可证。源码、构建配置、测试全部公开在 github.com/AAAduck/VaultGuard，可复现构建。

威胁模型

VaultGuard 解决的问题是：让普通"人"看不到、读不出你的文件。它不是万能盾牌，能防什么、防不了什么，如实列出。

防护目标是否防护说明
网盘、聊天工具的服务方/管理员✅ 内容层面密文内容无法读取；但文件的存在与统计特征可能被系统识别为"非普通图片"
拿到文件的人（同事/家人/陌生人）✅显示为普通图片；即便怀疑也无口令无法解密
拿到程序与源码的攻击者✅（口令加密）Argon2id(64MiB, t=3, p=1) 派生口令密钥，无后门、无找回
网盘自动扫描/取证分析⚠️ 有限密文统计特征理论上可被识别；专业取证请用 VeraCrypt
忘记口令❌ 无解有意为之：不存在绕过路径
已删除数据的介质残留⚠️ 有限VGS2 删除会立即隐藏条目，但压缩前旧数据段仍保留；程序临时数据会覆写擦除

设计上的安全措施

  • 认证先行：AES-256-GCM 认证标记常量时间比较；解密侧先认证、通过后才把明文写入磁盘；
  • 临时数据擦除：保险箱会话关闭/程序退出时，解密出的临时明文用覆写方式擦除后删除；
  • 防跨壳改名：AAD 绑定格式版本与外壳类型，把加密文件从 PNG 改名成 JPG 会被认证拒绝；
  • 容错保存：VGS2 先落盘数据段、再落盘 manifest；末尾未完成或认证失败会回退到上一份已认证 manifest。压缩/换口令采用自校验后的原子替换；
  • 完全离线：无网络、无遥测、无账号，不引入第三方依赖的上传路径。

公开格式规范

容器格式全部公开、字节级可复现（VGS1 永远可解；新建保险箱使用 VGS2）。所有整数均为大端（Big-Endian）。

伪装容器（VG 系列）— 单次加密产物

格式用途密钥派生
VG\x03口令加密（推荐）Argon2id：m=64MiB, t=3, p=1，随机 16 字节盐；参数写入文件头，未来调整不影响旧文件解密
VG\x02内置密钥（无口令）内置主密钥 + HKDF-SHA256，仅防随手翻看
VG\x01旧版产物仅解密兼容；PBKDF2（600,000 次迭代）
  • 加密算法：AES-256-GCM 流式（GHASH 使用 RustCrypto ghash），认证标记 16 字节，常量时间比较；
  • AAD：绑定格式版本与外壳类型 → 跨外壳改名被拒绝；
  • 外壳：PNG（私有块 vGDT）/ JPG（APP15 段）/ DOCX（word/vaultData.bin），外层带正常封面图，数据藏在容器结构中；
  • 明文路径：加密侧 tar 流直通加密管道，明文不落盘；解密侧先认证后落位，临时明文用后覆写擦除。

历史保险箱（VGS1，.vgsafe）

字段长度内容
Magic4B"VGS1"
kid / m / t / p1+4+4+1B密钥派生类型与 Argon2id 参数（m=64MiB, t=3, p=1）
salt16B随机盐
nonce12BGCM nonce
主体变长AES-256-GCM(tar 流) + 16B 认证标记；AAD = "VGS1"
  • 兼容：VGS1 可正常打开和导出；界面确认后首次保存会升级为 VGS2，旧 VGS1 解密路径永久保留；
  • 防误删：启动清扫带活跃标记心跳，不会误删长时间打开的保险箱/解密预览。

VGS2 — 当前保险箱格式 已接管读写

打开只认证 manifest、保存按段追加，面向"1 万文件、5GB 级"资料库的日常管理：

  • 全局头 50B："VGS2"(4) + kid(1) + Argon2id m/t/p + salt(16) + nonce(12) + reserve(8)；
  • 段链布局：数据段（0x01）/ manifest 段（0x02）追加式串接；段头 33B = 类型(1) + 序号(8) + 数据长度(8) + nonce(12) + CRC32(4)；
  • 防重排/防拼接：段序号进 AAD（"VGS2" + 用途字节 + 序号(8B)；manifest = 0x00、数据 = 0x01），篡改即认证失败；段头自带 CRC32。尾部截断按设计回退到上一份已认证 manifest（它保障崩溃恢复，不提供对有能力回滚整个文件者的检测）；
  • manifest：扁平条目 [name_len(2)][name][is_dir(1)][size(8)][mtime(8)][seg(8)][tar_path_len(2)][tar_path]；名字/路径上限 4096B，条目上限 100 万，读取上限 64MiB（防恶意长度导致超大分配）。
  • 追加、回退与压缩：新增追加数据段和新 manifest；删除/改名/移动只追加 manifest。末尾 manifest 未写完或认证失败时回退到上一版。删除立刻不可见，但物理旧段仅会在「压缩保险箱」或自动压缩（垃圾率 >30% 且 >256MB，或 32 份 manifest）时回收。

安装与校验

手动下载（当前推荐）

  1. 到 GitHub Releases 下载 VaultGuard.exe 与 SHA256SUMS；
  2. 把两者放到同一目录，执行校验：
Get-FileHash .\VaultGuard.exe -Algorithm SHA256   # 将 Hash 与 SHA256SUMS 比对

官方发行件由 GitHub Actions CI 构建，版本号/公司信息内嵌；每次打 tag 自动生成 Release。

Scoop

清单已就绪（distrib/scoop/VaultGuard.json，含自动更新配置），提交到 ScoopInstaller/Extras 或自有 bucket 后即可：

scoop install vaultguard

winget

清单已就绪（distrib/winget/，portable 单文件），上架 microsoft/winget-pkgs 需要清单代码签名，随项目代码签名决策落地。

构建与安全审计

  • 测试：cargo test --release —— 35 个自动化测试，覆盖既有容器与保险箱功能，以及 VGS2 向量、追加索引、损坏回退、压缩和 VGS1 升级；
  • 依赖审计：cargo audit 每周定时在 CI 自动运行，Cargo.lock 变更时也会触发；
  • 性能基准：tools/run_vgs2_bench.ps1 + vgs2-bench（本机跑，CI 不跑）；目标档（1 万文件 / 5GiB）实测：打开 0.22s、首次保存 26s、全量压缩 50s（原始数据见 docs/benchmarks/）；
  • 可复现构建：源码公开，任何人可自行构建比对产物哈希。

后续路线（v2.1+）

  • 性能纵深：多段并行加解密（突破 GCM 单线程上限）、增量段级 GC（删除大文件只重写所在段）；
  • 分发与信任：代码签名（消除 SmartScreen 冷启动警告）、winget / Scoop 上架、公开格式规范文档；
  • 产品项：多语言（英文）、安装版 + 右键菜单集成；
  • 生态：第三方安全审计、跨平台只读/导出命令行工具（macOS / Linux）；
  • 不做：对抗扫描、云同步 / 账号 / 遥测、密码管理器扩张。
