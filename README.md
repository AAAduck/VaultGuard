# VaultGuard — 把文件变成一张"图片"的加密保险箱

![CI](https://github.com/AAAduck/VaultGuard/actions/workflows/ci.yml/badge.svg)

## 这是个什么软件？

一句话：**它能把你的私密文件变成一张看起来完全正常的图片（或 Word 文档），存网盘、发给别人都行；只有知道口令的你（或你指定的人），能用它把文件还原回来。**

举个例子：你有一份工资单想存到网盘。用它加密后，网盘里出现的是一张风景图 `VG_20260906_3f8a.png`——谁看了都以为就是张图。哪天你需要，把这张图拖回软件、输入口令，工资单原样回来了。

全程在你的电脑上完成，**不需要联网**，不注册账号，只有一个 5MB 的 exe 文件。

## 什么场景下有用？

**✅ 场景一：网盘里存私密文件**
证件扫描件、工资单、日记、病历……直接放网盘总觉得不踏实。加密后再上传，网盘只能存一张"图片"，看不到也读不出里面的内容。

**✅ 场景二：把私密文件发给指定的人**
把加密后的"图片"通过微信/邮件发给对方，口令用电话或别的渠道告诉对方。对方装上本软件、拖入文件、输入口令即可还原。别人就算拿到文件，看到的也只是张普通图片。

**✅ 场景三：电脑里的文件防随手翻看**
文件伪装成图片放在电脑里，家人朋友、借电脑用的人不会起疑点开。配合口令，翻到了也打不开。

**✅ 场景四：长期整理重要资料**
用「隐私保险箱」功能，一个口令对应一个资料库，平时随时往里面加文件、删文件，像用一个加密文件夹一样。

**⚠️ 什么场景别用它（诚实说明）**
- **忘记口令，神仙也救不回来**——本软件没有"找回口令"功能，这是安全性的代价；
- 它防的是"人"，不保证骗过网盘的自动扫描系统（加密数据的统计特征理论上可以被识别为异常）。**请勿存放违法违规内容**，并请遵守网盘服务条款和当地法律；
- 面对专业黑客和取证分析，请使用 VeraCrypt 等专业工具。

## 三步上手（图形界面）

1. **添加文件**：把文件或文件夹**拖进窗口**（或点左栏「文件」「文件夹」按钮）；
2. **设置口令**：在左栏「口令」区输入口令，再输一遍确认。**口令是唯一的钥匙，忘了就打不开了**，请务必记牢。真的不想设口令，也可以点「跳过口令」，但那样任何拿到本程序的人都能解密（不推荐）；
3. **选外壳、点加密**：选一个伪装外壳（PNG 图片 / JPG 图片 / DOCX 文档），点绿色大按钮「开始加密」。

完成后，日志区会告诉你加密文件保存在哪了（默认在 `outputs\` 文件夹）。

**还原**：把加密产物（那张"图片"）拖回窗口，输入同一个口令，点「还原 VaultGuard 文件」，文件就回来了。还原不会动你的原文件，加密和还原都生成新副本。

## 常见问题

**Q：忘记口令了怎么办？**
无法找回。这是安全性的一部分——没有后门，谁都解不开（包括作者）。所以口令请设置得自己记得住，重要口令建议抄在纸上放安全的地方。

**Q：加密后的"图片"发到网上，别人能看出破绽吗？**
别人看到的是一张正常显示的图片。但内容已被加密，懂技术的人或网盘的自动系统**有可能**识别出"这个文件里藏了东西"。所以：用来保护个人隐私没问题，**不要用来藏违规内容**。

**Q：口令输错了会怎样？**
软件会提示"认证失败：口令错误"，**文件不会损坏**，重新输对口令即可。

**Q：加密后原来的文件还在吗？**
在。加密和还原都生成新文件，绝不动你的原文件。

**Q：这个软件联网吗？会收集我的信息吗？**
完全离线运行，没有任何联网、上传、遥测功能。

**Q：不设口令会怎么样？**
文件用的是"内置密钥"——**任何拿到本软件的人都能解密**。它只防"别人不知道有这个软件"。存敏感文件请务必设置口令。

**Q：直接把加密文件发给别人可以吗？**
可以！把"图片"文件发给对方，再用**别的渠道**（比如电话、微信语音）告诉对方口令。对方需要同样有 `VaultGuard.exe`。

**Q：杀毒软件报毒（如 VHO:Trojan-PSW...）怎么办？**
这是对**未签名、新编译**程序常见的启发式误报（VHO = 启发式判定，不是已知病毒库命中）。程序源码完全公开、完全离线，无任何联网/上传/键盘记录行为。处理步骤：
1. **先核验文件未被篡改**：到 GitHub Releases 下载 `SHA256SUMS`，在 exe 同目录执行 `sha256sum -c SHA256SUMS`，一致即文件没被动过手脚；
2. **提交误报申诉**：到 [opentip.kaspersky.com](https://opentip.kaspersky.com) 上传 exe，选 False Positive，卡巴更新病毒库后全局解除；
3. **本地加白名单**：杀软排除列表加入 exe（或整个文件夹），应急可先用；
4. 官方发行件来自 GitHub Actions CI 构建（版本号/公司信息内嵌），每次打 tag 自动生成。

## 进阶：隐私保险箱（长期整理推荐）

如果经常要往里放文件，每次打伪装包会很麻烦。用「隐私保险箱」页（窗口顶部切换）：

1. 输入保存位置和口令，点「新建」——生成一个 `.vgsafe` 文件；
2. 打开后随时「添加文件 / 添加文件夹 / 移除选中」，每次修改自动重新加密保存；
3. 勾选「添加时按类型归档到子目录」后，添加的文件会自动按扩展名分进 `图片 / 文档 / 压缩包 / 音频 / 视频 / 其他`，文件夹仍放根目录；
4. 「导出全部 / 导出选中」把文件解密出来；「更换口令」随时换口令。

关闭程序时，箱内解密出来的临时数据会自动擦除。

## 进阶：命令行（可选）

```powershell
# 口令加密（推荐）
VaultGuard.exe "D:\资料\项目文件夹" --png --password "我的口令"

# 还原（口令文件必须带对口令）
VaultGuard.exe "D:\资料\备份.png" --password "我的口令" --no-msg

# 口令不进命令行历史（推荐）
VaultGuard.exe "D:\资料\项目文件夹" --png --password-stdin
```

说明：直接拖文件到 exe 上也能用（默认 PNG 外壳）；产物重名会自动加 `_2`、`_3` 后缀，不会覆盖；`--keep-name` 可保留原文件名（默认输出随机名，不泄露原文件名）；`--no-msg` 结果写入 `vg_cli.log`；输出位置可用环境变量 `VG_OUT_ROOT` 指定。**注意：`--password "口令"` 会把口令暴露在进程列表与脚本历史中，脚本场景请优先使用 `--password-stdin`。**

## 以下内容给懂技术的读者

### 安全模型

| 模式 | 格式 | 密钥 | 防护范围 |
| --- | --- | --- | --- |
| 口令加密（推荐） | VG\03 | Argon2id(64MiB, t=3, p=1, 随机盐) 派生 | 不知道口令就无法解密，包括持有程序/源码的人 |
| 内置密钥 | VG\02 | 内置主密钥 + HKDF-SHA256 | 仅防随手翻看 |

- 加密算法：AES-256-GCM（流式，GHASH 使用 RustCrypto `ghash` crate），认证标记校验使用常量时间比较，AAD 绑定格式版本与外壳类型（跨外壳改名会被拒绝）；
- 加密侧 tar 流直通加密管道，明文不落盘；解密侧先认证后落位，临时明文用后覆写擦除；

### 构建与源码

源码在 `VaultGuard_rs/`，构建说明见 [VaultGuard_rs/README.md](VaultGuard_rs/README.md)。`cargo test --release` 包含 30 个自动化测试（3 容器 × v2/v3、目录、中文名、二进制、错误口令、保险箱全生命周期、口令更换、选择性还原、条目重命名/移动、目录前缀整理、嵌套导出、DOCX 超长记录拒绝、启动清扫逻辑、口令提醒逻辑）。

### 文件说明

```text
VaultGuard.exe          # Windows 发布程序（图形界面 + 命令行，单文件）
README.md               # 使用说明
VaultGuard_rs/          # Rust 源码、构建配置与内嵌资源
outputs/                # 默认输出目录
```

构建与源码说明见 [VaultGuard_rs/README.md](VaultGuard_rs/README.md)。运行程序不需要安装 Rust、Python、Zig 或其他运行时依赖。
